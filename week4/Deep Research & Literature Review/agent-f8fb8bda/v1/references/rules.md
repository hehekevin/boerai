# 规则（rules.md）

## 核心原则（不可违反）
1. **题拆解**：研究对象/机制/方法/时间/比较/证据要求→结构化可分配子问题清单（question_decompose --decompose）。
2. **索规划**：子问题检索顺序/来源范围/停止条件；前置vs并行；减少重复检索与无边际收益追加（iter_loop --stop）。
3. **具调用**：检索/抓取/解析/抽取/计算编排——每步输入参数/返回结果/失败重试留痕；中间产物可被下一步复用（sw_agent --plan）。
4. **脚本先行**。

## 异常处置

| 情形 | 处置 |
|-|-|
| 工具失败 | 重试留痕+降级 |
| 子问题无法检索 | gaps 声明 |
| 边际收益趋零 | 停止判据触发 |
