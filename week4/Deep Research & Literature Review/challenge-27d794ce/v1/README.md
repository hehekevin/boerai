# deep-research-forge

深度研究工具，支持文献综述、研究前沿分析、多文档整合

## 题目信息

- **题目ID**: challenge-27d794ce
- **题目**: 深度研究与文献综述领域总课题
- **赛道**: Deep Research & Literature Review
- **版本**: v1

## 快速开始

1. 阅读 SKILL.md 了解功能和使用方法
2. 准备输入数据
3. 运行工具生成结果
4. 审核输出质量

## 文件说明

- `SKILL.md`: 详细的技能说明文档
- `README.md`: 本说明文件
- `examples/`: 示例文件目录
- `templates/`: 模板文件目录
- `references/`: 参考资料目录

## 依赖要求

- Python 3.8+
- 相关依赖包见 requirements.txt
