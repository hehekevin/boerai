# 规则（rules.md）

## 核心原则（不可违反）
1. **述统计**：样本量/中心/离散/分位数/形态正确；缺失/异常/重复处理；每个统计量口径与单位说明（stats_viz --descriptive）。
2. **断统计**：按分布/样本量/设计选检验；先正态性/方差齐性；多重比较与配对处理；避免误用（stats_viz --testpick）。
3. **效应量**：与设计匹配的效应量（标准化均值差/解释比例/关联强度）；口径/方向/置信区间（stats_viz --effectsize）。
4. **脚本先行**。

## 异常处置

| 情形 | 处置 |
|-|-|
| 数据类型混列 | 类型过滤+标记 |
| 前提不满足 | 非参数替代 |
| 效应量缺CI | 标注缺失 |
