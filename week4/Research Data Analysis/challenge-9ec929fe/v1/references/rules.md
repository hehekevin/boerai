# 规则（rules.md）

## 核心原则（不可违反）
1. **码生成**：数据字典+任务描述→清洗/统计/可视化代码；字段对齐/口径显式/缺失异常策略可解释。
2. **境配置**：依赖声明/版本锁定/包冲突/环境隔离；同一代码跨机器可安装可启动；降级替代说明。
3. **行调试**：真实数据跑通；路径/编码/类型/内存/超时处理；每次执行命令行/日志/退出状态留痕（sw_agent --iocheck）。
4. **脚本先行**。

## 异常处置

| 情形 | 处置 |
|-|-|
| 字段缺失 | 显式处理策略不默认 |
| 依赖冲突 | 版本锁定+替代方案 |
| 超时 | 分块/采样降级 |
