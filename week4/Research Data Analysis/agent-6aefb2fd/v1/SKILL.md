# research-data-analysis-forge

## 功能概述

科研数据分析工具，支持数据清洗、统计分析、可视化

## 核心能力

- 数据处理、统计分析、图表生成、结果解释
- 智能分析与建议
- 结构化输出
- 可追溯的工作流程

## 输入要求

- 题目ID: agent-6aefb2fd
- 题目: 多步骤数据分析 Agent
- 赛道: Research Data Analysis

## 工作流程

1. **需求分析**: 理解题目要求和评分标准
2. **方案设计**: 设计解决方案和实施策略
3. **执行实施**: 按照方案逐步执行
4. **质量检查**: 验证输出质量和完整性
5. **结果交付**: 生成最终交付物

## 输出规范

- 结构化、可追溯
- 符合学术规范
- 包含必要的引用和来源
- 提供清晰的说明文档

## 使用示例

```bash
# 调用示例
python3 research-data-analysis-forge.py --input data.json --output result.md
```

## 注意事项

- 确保输入数据的完整性
- 遵循学术诚信原则
- 保留所有中间步骤的记录
- 输出结果需要人工审核
