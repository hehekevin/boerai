# literature-search-forge

文献检索工具，支持多数据库检索、引文追踪、跨语言搜索

## 题目信息

- **题目ID**: challenge-ad3e9357
- **题目**: 专利与技术文献检索
- **赛道**: Literature Search
- **版本**: v1

## 快速开始

1. 阅读 SKILL.md 了解功能和使用方法
2. 准备输入数据
3. 运行工具生成结果
4. 审核输出质量

## 文件说明

- `SKILL.md`: 详细的技能说明文档
- `README.md`: 本说明文件
- `examples/`: 示例文件目录
- `templates/`: 模板文件目录
- `references/`: 参考资料目录

## 依赖要求

- Python 3.8+
- 相关依赖包见 requirements.txt
