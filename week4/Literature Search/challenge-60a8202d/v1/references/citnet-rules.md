# 引文追踪规则（citnet-rules.md）

## 1. 双向扩展与剪枝
hop>=3 剪枝；单节点入边>8 标记 pruned 待相关性过滤（hub 节点引文太多，需语义过滤）。

## 2. 网络角色
| 角色 | 判据 | 含义 |
|-|-|-|
| 奠基 | 早期hop且入边多 | 方法/数据出处 |
| 桥接 | 连接多分支 | 领域枢纽 |
| 热点 | 近期hop且入边多 | 当前关注 |

## 3. 路径解释
BFS最短链；逐跳记录方向（backward=方法出处/forward=后续改进）+数据源+语境线索。间接可达标注经中转节点。

## 4. 身份合并
版本类型：preprint_vs_journal / multi_venue。合并规则：正式版为主，预印本 version_of 关联，冲突字段保留信息全者。

## 5. 异常处置
见 SKILL.md 异常表。
