# 纳排筛选规则（screening-rules.md）

## 1. 检索协议五要素
数据库（各库语法方言分别写）、字段限定（title/abstract）、时间范围（起止+时区）、语种限制、检索日期（必填）。每要素与纳入标准的对应关系逐条写明。

## 2. 理由码表
| 码 | 含义 | 判据 |
|-|-|-|
| I1 | 主题相关 | 命中 PICO 全要素或同义词 |
| I2 | 研究类型符合 | 摘要含研究设计词（RCT/队列/实验/benchmark…） |
| E1 | 非研究性文献 | editorial/news/评论 |
| E2 | 语言不符 | 标题+摘要均非限定语种 |
| E3 | 人群重叠 | 与已纳入记录样本描述重叠 |
| pending | 信息不足 | 规则未命中，升级复核 |

## 3. PRISMA 计数闭合
检索→去重→标题摘要筛选→全文筛选，各阶段 n_in/n_out/n_excluded 逐环对账；排除必须引用理由码。

## 4. 冲突仲裁
标注分歧：记录分歧点+类型（纳排分歧/版本分歧）+仲裁结论+仲裁依据；实质性争议不合并。

## 5. 人工确认点
模型输出只在规则可判定时自动生效；以下必须人工：全文纳入终审、E3 重叠判定、与既有系统综述的一致性核对。

## 6. 异常处置
| 情形 | 处置 |
|-|-|
| 无标准表 | 骨架+模型起草+待确认标记 |
| 仅标题无摘要 | pending，不强行判定 |
| 计数不闭合 | 修复后再交付 |
| 编码异常 | UTF-8容错+anomalies记录 |
