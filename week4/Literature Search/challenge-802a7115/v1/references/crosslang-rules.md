# 跨语言检索规则（crosslang-rules.md）

## 1. 术语类型与置信度
| 类型 | 说明 | 命中置信度 |
|-|-|-|
| synonym | 规范同义词 | 高 |
| abbr | 缩写 | 高 |
| translit | 音译 | 低→必复核 |
| localname | 本地译名 | 低→必复核 |

## 2. 语种识别规则
CJK占比>15%→zh；纯拉丁→en；混合→mixed。版本判定：标题摘要语种不同→bilingual_journal（风险标记）。

## 3. 匹配证据
每条命中记录：命中的双语术语、类型、形态变体；多术语语义命中风险低，单术语/音译命中强制复核。

## 4. 误译复核
高风险命中做回译（记录翻译服务与版本）或人工抽检；"词面对应、语义不同"的假阳性记 false_positive_flag。

## 5. 异常处置
见 SKILL.md 异常表。
