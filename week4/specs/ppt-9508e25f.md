# 规格说明：ppt-9508e25f（学术 PPT 领域总课题）

## 选定问题
选题：材料到可放映文件的通用可核验链路（六类要素全覆盖）。

## 引擎机制映射（awkit 模块 → 用途）
- `structcheck`：主线
- `deck`：大纲/生成/预览
- `claims`：数字保真
- `coverage`：要素覆盖
- `revisions`：迭代

## 输入 / 输出
输入：论文/数据/模板；输出：deck.pptx、preview/、outline/deck_check/build/struct/versions、result.json

## 验收标准（机械可核）
- 三件套（可编辑源+真实预览+证据映射）齐备
- 材料缺口诚实标注

## 通用约束
- 纯 stdlib；python-pptx/matplotlib/LibreOffice 仅作 try/except 增强，不可用时有诚实兜底。
- 中间产物全部落盘 JSON 于 /app/work；result.json 含 case_id 与全部 output_contract 键。
- ≤50 文件 / ≤2MB / 无符号链接 / SKILL.md frontmatter 合法 / GITHUB_URL.txt 首行 GitHub 链接。
