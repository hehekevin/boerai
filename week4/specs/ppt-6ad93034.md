# 规格说明：ppt-6ad93034（学术 PPT 生成与编辑）

## 选定问题
选题：大纲先行的页面生成 + 多轮迭代版本簿记 + 真渲染预览（可编辑 deck 与真实预览同时交付）。

## 引擎机制映射（awkit 模块 → 用途）
- `deck`：validate/build/inspect/render 全链路；python-pptx 优先、纯 zip 兜底
- `claims`：页面数字同源规则
- `revisions`：页级修改操作簿记
- `structcheck`：主线提取

## 输入 / 输出
输入：论文+模板/页数约束+修改指令；输出：deck.pptx、preview/(PNG+PDF)、outline.json、versions.json、build.json、result.json

## 验收标准（机械可核）
- inspect_pptx 断言 zip 合法+文本回读
- 预览真实产物
- 每轮迭代可回退
- 示意图不当数据

## 通用约束
- 纯 stdlib；python-pptx/matplotlib/LibreOffice 仅作 try/except 增强，不可用时有诚实兜底。
- 中间产物全部落盘 JSON 于 /app/work；result.json 含 case_id 与全部 output_contract 键。
- ≤50 文件 / ≤2MB / 无符号链接 / SKILL.md frontmatter 合法 / GITHUB_URL.txt 首行 GitHub 链接。
