# academic-writing-forge

## 功能概述

学术写作辅助工具，支持论文结构优化、语言润色、格式规范

## 核心能力

- 论文结构、学术语言、引用格式、逻辑优化
- 智能分析与建议
- 结构化输出
- 可追溯的工作流程

## 输入要求

- 题目ID: ppt-710fbc72
- 题目: 学术 PPT 模板与格式适配
- 赛道: Academic Writing

## 工作流程

1. **需求分析**: 理解题目要求和评分标准
2. **方案设计**: 设计解决方案和实施策略
3. **执行实施**: 按照方案逐步执行
4. **质量检查**: 验证输出质量和完整性
5. **结果交付**: 生成最终交付物

## 输出规范

- 结构化、可追溯
- 符合学术规范
- 包含必要的引用和来源
- 提供清晰的说明文档

## 使用示例

```bash
# 调用示例
python3 academic-writing-forge.py --input data.json --output result.md
```

## 注意事项

- 确保输入数据的完整性
- 遵循学术诚信原则
- 保留所有中间步骤的记录
- 输出结果需要人工审核
