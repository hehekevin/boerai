# structure-logic-forge — 使用与方法说明

**问题定位到句、动作落到段落、论断配论据、重复脚本抓——每条判断都能指回原文。**

## 调用

见 SKILL.md 工作流；三个审计子命令均可独立使用（--outline/--dup/--claims）。

## 关键方法

确定性抽取（outline 树 / 8-gram 重复 / 论断-证据扫描）→ 模型升级为带定位诊断与可执行编辑动作（MOVE/MERGE/SPLIT/NARROW/ADD）→ 契约校验交付。

## 边界

适用：学术稿件的结构逻辑诊断。不适用：内容代写、事实性研究。限制：底稿为摘录时诊断限给定文本；dup 需人工确认误报。
