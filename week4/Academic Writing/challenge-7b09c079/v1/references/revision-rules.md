# 修订规则（revision-rules.md）

## 1. 指令落位四层

| 层 | 允许的动作 | 禁止 |
|-|-|-|
| 措辞 | 句内同义替换、语序调整 | 改数字改术语 |
| 结构 | 段移动/合并/拆分 | 删事实内容 |
| 术语 | 全篇统一替换 | 部分替换造成混用 |
| 引用 | 增删引用同步文献表 | 只改正文不改表 |

## 2. 修订记录

每条 `{id, layer, before, after, location, basis(指令号), status: proposed}`——可逐条接受/拒绝；拒绝不污染其他条目。

## 3. 编号一致性（格式不塌）

- [n] 引用按首现顺序连续；文献表从 1 连续；引用-表双向存在。
- 图表题注编号 vs 正文引用一致。
- 标题层级不跳级（## 后不直接 ####）。

## 4. 版本管理

- 基线 = case.json 指定版本；修订产新版本不覆盖；
- --diff 产物即版本差异记录，可回退。

## 5. 异常处置

指令模糊 → uncertainties；编号 FAIL → 先修；预算不足 → revisions.json 先落盘。
