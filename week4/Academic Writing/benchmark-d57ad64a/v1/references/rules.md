# 规则（rules.md）

## 核心原则（不可违反）
1. **判得动**：输入材料/指令/格式要求/必需要点齐备——两名评分员不商量能判出同一结论。
2. **站得住**：参考答案覆盖合法写法变体；不可接受错误与可接受差异分开——不只认一篇范文。
3. **打得齐**：评分锚点写成可观察现象；分歧集中在少数判据上。
4. **可复现**：相同输入/条件/权限复跑结论可解释一致。
5. **复用 bench_engine**：validate-card/score/panel 三子命令（0/1/2记分+争议标记）。

## 异常处置

| 情形 | 处置 |
|-|-|
| 规则不可机械判定 | 转人工流程声明 |
| 1分争议 | 人工复核队列 |
| 复跑波动 | 记录+解释 |
