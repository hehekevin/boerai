# 示意图规则（diagram-rules.md）

## 1. 关系图形语法（结构画错比难看更致命）

| 关系 | 图形 | 禁止 |
|-|-|-|
| 激活/促进 | 实线箭头 → | 不得用于抑制 |
| 抑制 | 平端短线 ┤ | 不得画成箭头 |
| 上下游 | 箭头方向 = 代谢/信号流向 | 方向依据必须在 map 里 |
| 包含 | 大圆套小圆 | 不得画成并列框 |
| 时序 | 编号 + 单向链 | 不闭环 |

方向依据：map 中每条关系带原文引用；来源未指明方向 → 不画箭头，gaps 追问。

## 2. 实体规范

- 实体名 = 来源原名（不改写、不缩写、不造新名——来源没有的基因名/浓度/时间点严禁出现）；
- 层级：分子<细胞器<细胞<组织；尺度关系用相对大小表达；
- 同类实体同形状，不同类不同形状。

## 3. 图例与数据映射

- 颜色数 = 数据分类数（逐行对应）；
- 图例项命名 = 数据表行名；
- 数据更新 → 只改数据绑定区重绘（SVG 结构支持）。

## 4. 版式

分区留白 ≥24px；连线避免交叉与穿文字；字号 ≥9px；配色低饱和。

## 5. 异常处置

方向不明 → gaps；图例不一致 → 以数据为准；指令指向不存在图层 → uncertainties；渲染器缺 → SVG+清单；预算不足 → map+SVG 先落盘。
