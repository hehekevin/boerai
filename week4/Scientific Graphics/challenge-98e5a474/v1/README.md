# diagram-forge — 科研示意图生成与编辑 — 使用与方法说明

**关系方向必有依据、实体不造新名、图例与数据逐项一致、SVG 分层可编辑——审稿人挑不出结构错误。**

## 调用

见 SKILL.md 工作流；svg_audit.py 可独立使用。

## 关键方法

实体-来源映射先行（每个上图元素都有出处）→ 确定性版式生成 SVG（text 可编辑、g 分层命名）→ 脚本审计（可编辑性/分层/图例/字号/画布）→ 源文件+导出件双交付。

## 边界

适用：科研示意图/图形摘要的生成与编辑。不适用：统计图表数值计算、艺术插画。限制：导出 PNG/PDF 需运行环境渲染器，无渲染器时交付 SVG 源 + 导出清单并声明。
