# scientific-graphics-forge

科研绘图工具，支持机制图、流程图、数据可视化

## 题目信息

- **题目ID**: challenge-1bd90d8a
- **题目**: 科研数据图表生成与编辑
- **赛道**: Scientific Graphics
- **版本**: v1

## 快速开始

1. 阅读 SKILL.md 了解功能和使用方法
2. 准备输入数据
3. 运行工具生成结果
4. 审核输出质量

## 文件说明

- `SKILL.md`: 详细的技能说明文档
- `README.md`: 本说明文件
- `examples/`: 示例文件目录
- `templates/`: 模板文件目录
- `references/`: 参考资料目录
