# scientific-graphics-forge

## 功能概述

科研绘图工具，支持机制图、流程图、数据可视化

## 核心能力

- 科学绘图、机制展示、数据可视化、图表美化
- 智能分析与建议
- 结构化输出
- 可追溯的工作流程

## 输入要求

- 题目ID: challenge-83d4f050
- 题目: 生物机制图与通路图
- 赛道: Scientific Graphics

## 工作流程

1. **需求分析**: 理解题目要求和评分标准
2. **方案设计**: 设计解决方案和实施策略
3. **执行实施**: 按照方案逐步执行
4. **质量检查**: 验证输出质量和完整性
5. **结果交付**: 生成最终交付物

## 输出规范

- 结构化、可追溯
- 符合学术规范
- 包含必要的引用和来源
- 提供清晰的说明文档

## 使用示例

```bash
# 调用示例
python3 scientific-graphics-forge.py --input data.json --output result.md
```
