# 图形摘要规则（diagram-rules.md）

## 1. 面板-要点映射

单页四区固定阅读序：问题 → 方法 → 结果 → 结论。每区一个 `<g data-role>`。

- 必上图：研究对象、方法主干（≤5 步）、1–3 个核心结果、结论一句话；
- 只进图注：实验细节、条件参数、次要结果；
- 来源没有的实体/数值不上图（element-source-map 每行有 file:line）。

## 2. 视觉编码

| 信息 | 编码 | 约束 |
|-|-|-|
| 方法步骤 | 圆角矩形 + 箭头 | 单向流动，不自交叉 |
| 因果/抑制 | 实线箭头 / 平端短线 | 方向必须与文字一致 |
| 数值大小 | 长度/面积 | 长度优先（面积易误读） |
| 分组 | 颜色 | ≥4 色必须图例；主色对加形状冗余（色觉/灰度） |
| 条件标签 | 文字 | ≥9px |

## 3. 版式

- 画布：按任务要求；默认 1200×600 viewBox，白底；
- 面板留白 ≥24px，面板间对齐；
- 阅读序：左→右、上→下，箭头引导。

## 4. 可编辑与导出

- SVG 源：`<text>` 文字（禁轮廓化）、g 分层命名、defs 集中管理颜色；
- 导出：PNG（≥300dpi 等效尺寸）+ PDF（矢量）；字体嵌入或转通用字体；
- 导出清单：`{format, path, dpi, notes}`。

## 5. 异常处置

材料缺段 → 面板占位+gaps；渲染器缺 → SVG+清单；冲突 → 文字为准+conflicts；预算不足 → map+SVG 先落盘。
