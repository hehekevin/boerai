# 公式解析规则（formula-rules.md）

## 1. 线性化约定（MathML → 可读形式）

| MathML | 线性化 |
|-|-|
| mfrac(a,b) | (a)/(b) |
| msub(x,i) | x_{i} |
| msup(x,n) | x^{n} |
| msubsup(x,i,n) | x_{i}^{n} |
| msqrt(a) | sqrt(a) |
| mrow/math | 子元素按序拼接 |

- 希腊字母保留 Unicode 原字符（α β γ …），不转拼音不转英文描述。
- 上标为负指数的写 `10^{-3}`，不写 e-3。
- 矩阵/分段函数线性化为行序拼接 + `<!-- 结构：m x n 矩阵 / 分段函数 -->` 注释，不丢行列。

## 2. 变量三级分类（讲得清）

| class | 判据 | 处置 |
|-|-|-|
| 原文定义 | 材料有定义句（file:line 可指） | 直接入表 |
| 上下文推断 | 无定义句，但上下文唯一合理 | 入表 + 标注"上下文推断" |
| 常识补充 | 通用数学记号（e、π、Σ） | 入表 + 标注"常识补充" |
| （缺失） | 皆不满足 | **不入表**；gaps + human_confirm |

同符号多义（如 T 既当温度又当周期）→ 每处出现单列条目，human_confirm。

## 3. 推导步骤格式（推得顺）

```
S1: 输入=式(1)；操作=两边取对数；输出=ln y = a + b x；假设=y>0，x 与 y 正相关
S2: 输入=S1、式(3)；操作=代入 a=0.5；输出=…；近似=小扰动线性化
```
每步必须含：输入、操作、输出、假设/近似/边界条件。跨公式引用写成依赖（"依赖：式(3)"）。

## 4. 数值代入（算得回）

- 只用脚本 --numeric（safe_eval，仅算术与括号），中间值逐条记录。
- 复算结果与原文声称值比对：相对误差 >1% 即记 conflict（写明两边数值、来源、可能原因：舍入/单位/符号笔误）。
- 单位不一致只标记不换算（换算引入新数值）。
