# 示例说明（synthetic, not formal case results）

本目录与 `selftest.py` 中使用的所有数据均为**人工编造的合成数据**：
合成论文段落、合成题卡、合成批注与合成文件库。它们只用于演示引擎接口
与端到端流程（probe → extract → blocks → 赛道命令 → emit → result.json），
**不是**平台固定案例的正式运行结果，不构成任何效果证据。

- 正式案例由平台统一提供并运行；本技能不预制答案。
- 运行 `python selftest.py` 可复现全部 demo（每模块一个 `_demo()`，
  内含断言自证）与一次端到端合成案例。
- 合成数据中出现的论文、作者、数值（如 "520 MPa"、"1.62 eV"）均为演示
  占位，不指向任何真实文献。
