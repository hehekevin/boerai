# 关系保真翻译规则（translation-rules.md）

翻译时最易失真的五类关系，逐条对照执行。

## 1. 指代对象

- 代词（it/they/this/these）翻译前先确认指代物；指代物距代词超过两句或跨段时，译文用名词复指："该方法（即 3.2 节所述的数据增强）"。
- "the former / the latter" 显式写出所指对象，不译成"前者/后者"后让读者回翻。
- 指代拿不准：保守直译 + 【译注：it 指代对象存疑，可能为 X 或 Y】。

## 2. 否定与限定

- not / no / never / neither / unless / except 的辖域宁窄勿宽；长句中的部分否定（not all = 并非所有）不得译成全盘否定。
- only / merely / at least / up to / approximately 等限定词必须保留，不得为通顺删除。
- 双重否定保持原逻辑，不擅自改成肯定句。

## 3. 因果与让步

- because / since / due to / therefore / however / although / despite 关系词显式保留；"X, Y" 两个独立句之间原文无因果词时**不得**补"因此"——这是最常见的过译。
- 让步从句不得译成转折后省略结论。

## 4. 数字与单位

- 数字、单位、百分比、区间照抄：3.5±0.2 mL/min、p < 0.001、95% CI [12.3, 15.8]。
- 千分位与小数点记号保持原文写法（1,024 不改 1024；3.5 不改 3,5）。
- 原文疑似笔误（如单位自相矛盾）照抄并在【译注】指出，不代改。

## 5. 公式与文献编号

- 行内变量、上下标、希腊字母在纯文本中按原样保留（α、β²、x_i）。
- 公式引用 Eq. (3)、编号 (1)–(5) 保留；公式本体为图片时按 edge-cases 处理。
- 文献编号 [12] 保留原位；文中 "Ref. [7] shows..." 译为 "文献 [7] 表明..."，编号不动。

## 6. 长句切分

- 英文长句拆译允许，但拆分点不得制造原文没有的逻辑关系；拆分处可用冒号/分号衔接。
- 拆分后每个子句的限定成分（定语从句、状语）不得丢失。

## 7. 禁止事项

- 增译原文没有的数值、结论强度（"significant" 原文没有就不得出现"显著"）。
- 删译限定条件、样本量、例外情形。
- 同一术语中途换译名（全篇以术语表为准，新术语先入表）。
- 把"未报告/不明确"译成肯定陈述。
