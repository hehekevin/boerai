# 文献问答规则（qa-rules.md）

## 1. 跨语言检索
中文问题→ZH_EN_MAP 术语扩展（准确率→accuracy、基线→baseline、未报告→not reported 等科研高频对照）→英文段落匹配（CJK bigram+latin词）。零命中时二次扩展+全文扫描。

## 2. 证据锚点格式
每条论断：`[论文ID 段落N "短引文≤40字"]`。短引文从原文逐字截取，不改写。

## 3. 语义类型三分类
| 类型 | 判据 | 表述要求 |
|-|-|-|
| 实测结果 | Results段落数值/实验数据 | 直接引用，保留单位与条件 |
| 作者解释 | Discussion 解释性语句 | 标"作者认为" |
| 自己推断 | 材料未直接陈述 | 标"推断"+推断依据 |

## 4. 不确定性处理
| 情形 | 处置 |
|-|-|
| 材料未报告 | "论文未报告X，无法确定" |
| 部分可答 | 给出可答部分+列出缺口 |
| 原文冲突 | 引用两处原文说明冲突 |
| 读取失败 | 明确报告失败原因 |

## 5. 异常处置
见 SKILL.md 异常表。
