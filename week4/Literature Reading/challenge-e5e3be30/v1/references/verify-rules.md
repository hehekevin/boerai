# 核验规则（verify-rules.md）

## 1. 论断类型与所需证据
| 类型 | 判据 | 所需证据 |
|-|-|-|
| fact | 陈述句 | 直接陈述 |
| comparison | 高于/低于/超过 | 数值+方向+对象 |
| causal | 导致/由于/因此 | 机制或因果实验 |
| +scope | 仅/只/在…条件下 | 事实+适用范围 |

## 2. 支持度四档
| 档 | 判据 |
|-|-|
| 支持 | 词汇重叠>=0.6+方向一致+陈述性表述 |
| 部分支持 | 提示性表述（suggest/may）或重叠0.45-0.6 |
| 不支持 | 方向相反（否定冲突） |
| 不充分 | 重叠<0.3（主题关联弱） |
主题相关≠支持：0.3-0.45重叠标 topic_related_only。

## 3. 跨语言对齐
中文论断经 ZH_EN_MAP 扩展后与英文证据重叠比对；未覆盖术语入 gaps。

## 4. 异常处置
见 SKILL.md 异常表。
